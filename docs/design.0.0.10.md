# LogFilterPro v0.0.10 — 修复 `!pivot` 分隔线对齐

## 目标

修复 `!pivot` 输出的表格中，表头/数据行的竖线 `│` 与分隔线的交叉符 `┿` 错位的问题。

## 根因

数据行和表头行的列分隔符为 `' │ '`（空格+竖线+空格，3 字符），而分隔线的交叉符 `┿` 只占 1 字符。每列偏移 2 字符，且首列前还有一个空格偏移，导致 `┿` 与 `│` 逐列错位。

## 改动

在 `src/filterEngine.ts:398` 中，分隔线构造增加偏移补偿：

- 行标签区：`rowWidth` → `rowWidth + 1`（补齐标签后的空格位置）
- 每列区：`colWidths[i]` → `colWidths[i] + 2`（补齐 ` │ ` 与 `┿` 的宽度差）
